## ⚙️ What It Does

| Feature | Description |
|---------|-------------|
| **CPU Priority Boost** | Raises the game process priority so the OS delivers frames more consistently. |
| **Memory Cleanup** | Flushes unused working sets to reduce micro‑stutters during heavy scenes. |
| **Network Latency Tweaks** | Disables Nagle’s algorithm for the game to improve hit‑reg and reduce ping spikes. |
| **GPU Scheduling** | Enables Hardware‑Accelerated GPU Scheduling (HAGS) to cut render latency. |
| **Background Trimming** | Suspends non‑essential processes while you play — more resources for the game. |
| **One‑Click Restore** | Every change is journaled. Restore the original state of your system in a single click. |

## ❓ Frequently Asked Questions

**Is MW4 Optimizer free?**  
Yes. The tool is released under the MIT License — free to use, inspect, and modify. The source code is available on GitHub.

**Will it get me banned?**  
No. The tool does **not** touch the game process memory or anti‑cheat. It only applies documented Windows APIs to the system, exactly as a user could do manually via Task Manager or Registry Editor.

**Do I need administrator rights?**  
Yes — a few of the system tweaks (such as process priority and registry settings) require elevation. Right‑click the executable and choose **Run as administrator**.

**How do I revert all changes?**  
Open the tool and click **Restore Defaults**. Every change is journaled, so the original state is restored precisely.

**Does it work with other Call of Duty titles?**  
MW4 Optimizer is tuned for **Modern Warfare 4**. Some features (CPU priority, memory cleanup) will work for any game, but the network and process detection logic is MW4‑specific.

**How do I verify the archive integrity?**  
Compare the **SHA‑256** hash of your downloaded archive against the value published in [SECURITY.md](SECURITY.md). Never run a build whose hash does not match.
